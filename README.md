# Responsive Landing Page

## Project Overview

This project is a simple landing page built using HTML and CSS. The page was enhanced to become mobile-friendly using CSS Media Queries, ensuring a responsive layout across different screen sizes and devices.

## Objective

Convert a desktop-only webpage into a responsive website that adapts seamlessly to mobile screens.

## Technologies Used

* HTML5
* CSS3
* Flexbox
* CSS Media Queries
* Chrome DevTools

## Features

* Responsive Header Navigation
* Mobile-Friendly Layout
* Flexible Typography
* Responsive Button Design
* Cross-Device Compatibility

## Responsive Design Implementation

The website uses CSS Media Queries with a breakpoint of 768px to:

* Stack header elements vertically on smaller screens
* Adjust font sizes for better readability
* Improve navigation accessibility on mobile devices
* Optimize spacing and layout for various screen sizes

## Testing

The website was tested using Chrome DevTools on:

* Desktop View
* iPhone 14 Pro Max View
